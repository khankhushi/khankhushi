### What I've been doing

At Deloitte I work on Salesforce Data Cloud for Fortune 500 clients, most recently a global biotech company and a US wealth management firm. Day to day, that looks like:

- stitching **~1-2M patient and customer records** from a bunch of different sources into single, clean customer profiles
- writing SQL and Python to validate and transform data, chasing bad records back to where they came from, and automating the checks we used to run by hand
- building engagement dashboards, which cut reporting time by **~20%**
- building SFMC segments that power personalised campaigns

That work earned me a **Deloitte Applause Award**, which I'm really proud of.
